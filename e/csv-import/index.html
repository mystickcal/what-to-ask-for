CSV import

Also called: spreadsheet import, bulk upload, Excel import, data import, import contacts

Taking a user's spreadsheet and turning rows into records. The safe shape is upload, map columns, preview with row-level errors, then commit all at once, with a row limit and the same validation as your forms.

You need it when

  • Users are switching from a spreadsheet or another tool.
  • Adding records one at a time would take them hours.

Skip it when

  • Users only ever have a handful of records.

Ways to build it

  1. Your own upload, preview, commit flow $0

    Parse with Python's csv module, Papa Parse (JavaScript) or openpyxl for Excel. Keep the parsed rows between steps, then save in one transaction.

    Tradeoff: Full control and private. Column mapping UI is the hard part.

  2. An embeddable importer free tiers or open source, then paid

    Flatfile, OneSchema, CSVBox or the open source react-spreadsheet-import give users a mapping and cleanup screen.

    Tradeoff: Great UX quickly. Data may pass through a vendor.

  3. Background import for big files $0

    Upload to storage, process in a job, email a report of what failed.

    Tradeoff: Handles large files. Users wait and come back.

Prompt for your coding agent

Replace the [bracketed] parts. Works in Claude Code, Cursor or Codex.

Add CSV import for [record type].

Requirements:
- Steps: upload, map columns (auto-match by header name), preview, commit.
- Limits: [500] rows and [5 MB] per file. Accept UTF-8 and UTF-8 with BOM. Detect comma or semicolon.
- Validate each row with the same rules as the normal create form. The preview shows each row's errors with row number and column.
- Commit valid rows in one transaction, or nothing on failure. Show "imported X, skipped Y" and offer a CSV of the skipped rows with reasons.
- Respect plan limits: check before commit that the import won't exceed them.
- Detect duplicates by [key] and let the user choose skip or update.
- Escape cells starting with =, +, -, @ when exporting the error file back, to block formula injection.
- Provide a downloadable template CSV.

Acceptance checks (run each and show me the result):
1. A file with 3 bad rows shows exactly those rows and reasons in the preview.
2. Killing the process during commit leaves no half import.
3. A file over the row limit gets a clear message.
4. Importing the same file twice doesn't create duplicates when skip is chosen.
5. A cell with =HYPERLINK(...) is neutralized in the error CSV.

If you skip it

Users import 10,000 broken rows they then have to delete by hand, or blow past plan limits in one upload.

How Derek runs it

Custody Journal's CSV import covers journal entries, expenses and calendar events. It goes upload, preview, commit, caps files at 500 data rows, and checks the free-tier monthly limit before committing.
